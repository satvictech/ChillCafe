## Names must match the website

The website sends orders across with the item name as the key, so the spelling
in LocSeva has to match `lib/menu.ts` exactly. If you rename a dish in one
place, rename it in the other.

Two names were shortened on both sides so they read properly:

| Board says | Now used everywhere |
|---|---|
| Spl. Chill Cafe Pizza | Chill Cafe Special Pizza |
| Spl. Marsroom Cheese Fried Rice | Mushroom Cheese Fried Rice |
